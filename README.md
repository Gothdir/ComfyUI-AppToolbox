# Comyfui-AppToolbox
A small  toolbox gadget for Appmode in ComfyUI. this was created mostly by Claude and for myself.

What is does:
It adds a small Gadget that you can drag around with terminal information, a Restart button and vram usage and a clear vram button.

<img width="425" height="405" alt="image" src="https://github.com/user-attachments/assets/6222fd33-e246-4013-b83e-eec9440f28eb" />

Requirements:

ComyfyUI Manager (which is included by defaulkt in ComfyUI these days)

Install:

git the repo into .\ComfyUI\custom_nodes
or download the folder and exract it into .\ComfyUI\custom_nodes folder

Restart ComfyUI
