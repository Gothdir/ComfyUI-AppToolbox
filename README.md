# ComfyUI-AppToolbox
A small  toolbox gadget for Appmode in ComfyUI. this was created mostly by Claude and for myself.

What is does:
It adds a small Gadget that you can drag around with terminal information, a Restart button and vram usage and a clear vram button.

## Requirements

ComyfyUI Manager
```bash
https://github.com/Comfy-Org/ComfyUI-Manager
```
## Install

Clone the repo into .\ComfyUI\custom_nodes

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/Gothdir/ComfyUI-AppToolbox.git
```

Restart ComfyUI
