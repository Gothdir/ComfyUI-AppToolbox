# ComfyUI-AppToolbox
A small  toolbox gadget for Appmode in ComfyUI. The code was mostly written by Claude.

Features:
- movable Widget
- Vram, Ram usage
- Vram and Ram cleaner
- Restart button
- Console
- Progression status
- Experimental: Model Download

## Requirements

ComyfyUI Manager
```bash
https://github.com/Comfy-Org/ComfyUI-Manager
```
## Install

Clone the repo into .\ComfyUI\custom_nodes

```bash
cd ComfyUI/custom_nodes
git clone https://github.com/Gothdir/ComfyUI-AppToolbox.git
```

Restart ComfyUI

## Model Download
